# ZYRA Intel Manifests

This directory contains machine-readable public-source intelligence contracts used by ZYRA/RVIA.

- [`rvia-federal-intel.json`](rvia-federal-intel.json) — CIA, NSA, NRO, NGP/NGA, and GDIP/DIA public-source registry.

Policy and integration notes: [`../docs/RVIA-FEDERAL-INTEL.md`](../docs/RVIA-FEDERAL-INTEL.md)

All entries are limited to public, lawfully accessible material. A source is marked official only when its government or official GitHub provenance has been verified.
