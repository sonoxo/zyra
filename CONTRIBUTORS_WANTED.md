## Fast first contribution

Pick one starter task, fork the repo, create a focused branch, run the documented checks, and open a pull request using the repository template.

Contributions are credited through Git history and merged pull requests. Consequential actions such as signing transactions, moving assets, governance voting or production deployment remain human-controlled.
