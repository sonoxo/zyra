# Contributor Start Here

Welcome to the ZYRA / XUNIA Glass Onion ecosystem.

Pick one lane instead of learning the whole stack at once:

- **ZYRA / TypeScript** — UI, API, workflows, tests, developer experience.
- **Flow / Cadence** — contracts, scripts, transactions, emulator examples in XUNIA.
- **VA3LM / SAGI** — coding intelligence, planning, testing, guardrail logic.
- **Ontology** — objects, properties, links, functions, actions, evidence models.
- **Docs / Visuals** — beginner maps, diagrams, examples, explainers.

## First contribution

1. Fork the repository.
2. Create a focused branch.
3. Change one thing well.
4. Run the relevant tests.
5. Open a pull request with what changed and how you verified it.
