XUNIA // BROWSER TOOL // BEGINNER MODE

Clean up your YouTube subscriptions without losing control.

XuniDirect helps you scan your own subscriptions, filter by date or channel name, preview exactly what matches, and explicitly confirm before anything is unfollowed.

WHAT IT DOES

One narrow purpose. One clear workflow.

The extension is intentionally simple: it manages the authenticated user’s own YouTube subscriptions using the official YouTube Data API.

LOCAL RUN

Four steps from GitHub to Chrome.

This is the path to use when you want to test XuniDirect directly from the repository.

Terminal
git clone https://github.com/sonoxo/zyra.git
cd zyra/integrations/xunidirect-youtube-cleaner/chrome-web-store/extension
open .
Beginner tip: in chrome://extensions, click Load unpacked and select the actual extension folder — not a ZIP file.
ECOSYSTEM

Where XuniDirect fits.

XuniDirect is the browser tool. Zyra is the platform layer. Black House is the project governance layer. The official YouTube Data API handles the external subscription data and confirmed actions.
